# MarketSim

MarketSim is an interactive market-making and limit-order-book simulator.

## Planned Features

- Limit order book
- Matching engine
- Simulated market order flow
- Automated market maker
- Inventory-aware quoting
- P&L tracking
- Real-time dashboard
- Strategy comparison
- Market stress scenarios

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Python
- FastAPI
